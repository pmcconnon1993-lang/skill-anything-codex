# Select the evidence route

| Material | Useful evidence | Output and limit |
| --- | --- | --- |
| Website or service | Selected official docs, navigation to needed pages, actual connector/API contracts | Topic references and checked operations; a homepage does not cover the entire site |
| Repository | Pinned commit; entrypoints, relevant implementation, configuration and tests | Capability map with file/line references; do not execute source installers automatically |
| CLI | Existing executable identity, help, relevant implementation/docs, disposable invocation | Tested commands and failure behavior; help alone is documented capability |
| REST API | OpenAPI JSON or YAML plus actual request/response/auth contract | Selected endpoints and permitted fixture/read operation; schema success is not a live account test |
| Library | Public interface, dependencies and actual minimal example | Versioned recipe or wrapper; importing a package is not functional proof |
| Workflow | Supplied good result, inputs, transformations, decision points and output checks | Reusable procedure; preserve exact factual rules while leaving judgment flexible |
| PDF, paper, notes, transcript | Source text with pages/times/sections; OCR checked against image when needed | Topic knowledge and procedures; image-only or inaccessible content remains a gap |
| Existing skill | Original entrypoint, resources, invocation policy and scripts | Convert/adapt the package instead of flattening it into notes |

For a name alone, resolve the intended authoritative target before making
claims. Use a connector/API/CLI that already works when possible. Use a browser
when dynamic/private page state requires it and access is authorized. Follow
links selectively to answer the user's capability, preserving the coverage log.
Do not invent a route when the runtime, login, source or backend is missing.

Use a short analysis record: target identity, intended capability, read sources,
interface, dependencies, effects, evidence, checks and unknowns. Design follows
that evidence. Keep packaging and source-reading failures visible; they are
not permission to change the target or silently substitute a model.
